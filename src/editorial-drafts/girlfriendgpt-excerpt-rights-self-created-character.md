Identify who devised the character and what part of the conversation you plan to share. GirlfriendGPT's terms treat platform material and certain text from personal dialogues with characters you devised differently. The text exception is narrower than a broad right to republish anything shown on a profile.

## List the components you are sending

For an original fictional train dispatcher, write down which dialogue lines you composed and which lines appeared in the AI exchange. Check whether the crop also contains a portrait, username or interface elements. A prepared text extract can omit these other materials when all you need is a line of dialogue.

If the scene uses a character created by someone else, check the actual permission that applies. Save the permitted text or create a new example if access is unclear. An open profile does not tell you what another publisher allows you to reproduce. Consider the disclosure and distribution context separately from readability.

## Read it as a new recipient would

Read the exact excerpt without the preceding chat. If the text mentions someone's workplace, a private account or a real location you shared during drafting, remove or replace the identifying detail. GirlfriendGPT's privacy notice describes user-provided content, so avoid including a real person's data simply to make a sample scene vivid.

If your intended use is a public or commercial project, check the terms for that use and record any permission you actually received. Save the final extract with a brief source note. A later editor can then see which text you meant to share and which character and private details should stay out of it.
